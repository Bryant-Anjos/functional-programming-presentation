# Programação Funcional — Apresentação

Slide deck sobre **Programação Funcional** apresentado no **Field Hack**. Aborda os principais conceitos do paradigma funcional com exemplos práticos em JavaScript.

Construído com [Marp](https://marp.app/), que converte Markdown em slides de apresentação.

## Tópicos

- Paradigmas de programação (imperativos vs. declarativos)
- Funções puras
- Imutabilidade
- Recursão
- Transparência referencial
- First-class functions e Higher-order functions

## Visualizando os slides

```bash
npm install
npm run start   # preview com live reload
npm run build   # exportar para dist/
```

Ou abra `PITCHME.html` diretamente no browser para a versão estática.
